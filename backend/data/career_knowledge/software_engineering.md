# Software Engineering & Clean Architecture Guide

## Principles & Practices
1. **SOLID Principles**:
   - Single Responsibility Principle (SRP)
   - Open/Closed Principle (OCP)
   - Liskov Substitution Principle (LSP)
   - Interface Segregation Principle (ISP)
   - Dependency Inversion Principle (DIP)
2. **Design Patterns**:
   - Creational: Factory, Singleton, Builder.
   - Structural: Adapter, Decorator, Facade, Composite.
   - Behavioral: Strategy, Observer, Command, Chain of Responsibility.
3. **Clean Code & Testing**:
   - Unit testing, Integration testing, Mocking external boundaries.
   - CI/CD automation, linting, static code analysis.
   - Version control workflows (Git flow, branch protection, semantic commit messages).

## Resume Proof Points
- "Refactored monolithic service into clean modular architecture following SOLID principles, reducing bug regression rates by 35%."
- "Implemented comprehensive automated test suite with pytest achieving 88% branch coverage across backend services."
