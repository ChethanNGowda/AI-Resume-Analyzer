# Resume Writing & Professional Branding Guide

## Proven Resume Architecture
1. **Contact Information**: Full name, clean email address, phone number, location (City, State/Country), LinkedIn URL, GitHub profile, and portfolio URL. Do not include photo, marital status, or full street address.
2. **Professional Summary (Optional for entry level, mandatory for 3+ years experience)**:
   - 2-3 concise lines defining your primary role, years of experience, core tech stack, and strongest achievement.
3. **Technical Skills Section**:
   - Organize logically:
     - Languages: Python, JavaScript, TypeScript, SQL, Java, C++
     - Frameworks/Libraries: React, Flask, FastAPI, Node.js, pandas, scikit-learn
     - Databases & Storage: PostgreSQL, MySQL, MongoDB, Redis, ChromaDB
     - Developer Tools & Platforms: Docker, Git, GitHub Actions, AWS, Linux
4. **Work Experience & Internships**:
   - Reverse chronological order.
   - Use Google's formula for achievement bullets:
     - **"Accomplished [X] as measured by [Y] by doing [Z]"**
   - Start every bullet with a strong action verb (Engineered, Architected, Spearheaded, Accelerated, Optimized, Automated).
5. **Projects**:
   - Project Name, Tech Stack, Live Demo Link, GitHub Link.
   - 2-3 bullets per project detailing technical complexity, architecture decisions, and measured performance or user outcomes.
6. **Education**: Degree name, Major, University name, Graduation Year, CGPA/GPA (if strong >= 8.0/10 or 3.5/4.0).
