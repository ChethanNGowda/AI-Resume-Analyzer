# Technical Interview Preparation Guide

## Preparation Methodology
1. **Data Structures & Algorithms**:
   - Arrays, HashMaps, Strings, Two Pointers, Sliding Window.
   - Linked Lists, Trees (BST, BFS/DFS, Lowest Common Ancestor), Tries.
   - Graphs (Adjacency list, Dijkstra, Topological Sort, Union-Find).
   - Dynamic Programming (Memoization, Tabulation, 0/1 Knapsack, Longest Common Subsequence).
2. **Coding Interview Execution (The 5-Step Process)**:
   - **Step 1 - Clarify**: Ask about edge cases, inputs range, null inputs, duplicates, and constraints.
   - **Step 2 - Propose Approach**: State brute force first, then analyze time and space complexity ($O(N)$, $O(\log N)$). Discuss trade-offs before typing code.
   - **Step 3 - Code Cleanly**: Write modular, readable code with descriptive variable names.
   - **Step 4 - Dry Run**: Walk through a sample input manually line by line with the interviewer.
   - **Step 5 - Edge Cases**: Check empty arrays, single elements, negative numbers, overflow, boundary conditions.
3. **Explaining Projects During Technical Rounds**:
   - Use the **CAR** method: Context, Action, Result.
   - Be ready to explain: Why did you pick technology X over technology Y? What was the biggest technical bottleneck? How would you redesign it today for 100x traffic?
