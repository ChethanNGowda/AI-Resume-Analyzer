# Data Analytics Career & Interview Guide

## Core Competencies
A modern data analyst must master:
1. **SQL**: Window functions (ROW_NUMBER, RANK, DENSE_RANK), Common Table Expressions (CTEs), aggregation (GROUP BY, HAVING), multi-table joins, subqueries, and query performance optimization.
2. **Python for Data Analysis**: pandas (groupby, merge, pivot_table, loc/iloc), numpy, data cleansing, handling missing values, vectorization, and outlier detection.
3. **Data Visualization & BI**: Tableau, Power BI, Metabase. Designing dashboards with actionable metrics, drill-downs, DAX measures, and visual storytelling.
4. **Statistical Analysis**: Hypothesis testing, A/B testing evaluation, confidence intervals, p-values, correlation vs causation, linear regression, and churn analysis.
5. **Business Acumen**: Translating raw data into business ROI, customer acquisition cost (CAC), customer lifetime value (LTV), retention cohorts, and conversion funnels.

## Resume Proof Points for Data Analysts
- Quantify impact: "Automated daily reporting pipeline using Python and SQL, reducing manual reporting time by 15 hours per week."
- Showcase data scale: "Analyzed over 2.5 million transactional records to identify regional sales trends, driving a 12% boost in Q3 cross-sells."
- Name dashboard tools and users: "Designed executive Power BI dashboards with real-time KPI alerts used daily by 25+ senior stakeholders."

## Common Technical Interview Questions
- What is the difference between WHERE and HAVING in SQL?
  - WHERE filters rows before aggregation occurs; HAVING filters grouped rows after aggregation.
- Explain the difference between INNER JOIN, LEFT JOIN, and FULL OUTER JOIN.
- How do you handle missing data in pandas?
  - Assess whether data is Missing Completely at Random (MCAR). Options include dropna(), mean/median imputation, forward-fill (time series), or domain-specific indicators.
- How do you conduct an A/B test and determine statistical significance?
